# 시연 실행 스크립트

실제 Jetson 시연 환경에서 사용한 셸 스크립트와 Ubuntu desktop 바로가기를 기능별로 정리했습니다.

스크립트는 `/home/user/sw/robot`, `/home/user/turtlebot3_ws`, `/home/user/ros2_ws` 같은 당시 절대경로를 사용합니다. 현재 저장소 구조에서 실행을 보장하지 않으며 공식 설치·실행 인터페이스로 취급하지 않습니다.

- `final_demo/`에는 최종 비-Safety 통합 실행 체인이 있습니다.
- `component_demos/`에는 제스처, Wi-Fi 장갑, 소음 감지 단독 실행기가 있습니다.
- `setup/`에는 당시 Jetson 설치 스크립트가 있습니다.
