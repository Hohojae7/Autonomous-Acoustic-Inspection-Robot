# 최종 발표 기준 프로젝트 맥락

## 목표

TurtleBot3가 산업 현장을 자율 순찰하고 기어박스 소리를 점검하며, 필요할 때 작업자가 제스처나 IMU 장갑으로 수동 제어권을 넘겨받는 통합 시스템을 구현했습니다.

## 최종 기능 흐름

1. SLAM으로 작성한 지도에서 AMCL과 Nav2로 A 지점에서 B 지점까지 자율주행합니다.
2. B→C 구간은 MediaPipe 손 제스처로, C→D 구간은 컨트롤러 모드의 조이스틱 또는 Wi-Fi 장갑으로 수동 제어합니다.
3. D 지점에서 제어권을 다시 Nav2로 넘겨 A 지점으로 복귀합니다.
4. 웹캠 마이크 입력에서 MFCC 특징을 계산하고 SVM으로 정상·이상을 판정합니다.
5. 판정 상태를 ROS 2 토픽과 TurtleBot3 OpenCR LED에 표시합니다.

## 최종 웨이포인트

`factory_map_final` 지도와 `waypoint_handoff_mission.py`에 남은 최종 좌표입니다. 이전 날짜별 작업 기록의 좌표보다 이 값이 우선합니다.

| 지점 | X (m) | Y (m) | Yaw (rad) | 담당 제어 |
| --- | ---: | ---: | ---: | --- |
| A | 0.044 | -0.115 | 0.000 | 출발·복귀 |
| B | 1.429 | -0.213 | -1.579 | Nav2 |
| C | 1.376 | -1.451 | -1.559 | 손 제스처 |
| D | 0.124 | -1.482 | -3.113 | 컨트롤러 모드 |

## 정리 기준

- 최종 통합에서 사용한 비-Safety 소스를 핵심으로 분류했습니다.
- 막판에 취소한 Safety 기능과 기능 없이 반복 순찰하는 임시 데모는 정리본에서 제외했습니다.
- ROS 2 패키지는 `src/`, MediaPipe 애플리케이션과 펌웨어는 루트의 독립 구성요소로 배치했습니다.
- 기존 실행 환경을 완전히 복원하기보다 팀이 구현한 기능과 코드 역할을 알아보기 쉽게 보존합니다.
